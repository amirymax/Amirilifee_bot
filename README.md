# Amirilifee Bot

**Amirilifee Bot** — это Telegram-бот, разработанный на `aiogram 3`, предназначенный для распространения бесплатных уроков по созданию Telegram-ботов с использованием ChatGPT, а также инструкций по загрузке бота на сервер. Бот служит воронкой для вовлечения учеников в образовательную программу и поддерживает структуру как для пользователей, так и для администратора.

## 🔍 Основные функции

- 📚 **Доступ к бесплатным урокам**:
  - Уроки по созданию Telegram-ботов с ChatGPT
  - Уроки по загрузке бота на сервер

- ℹ️ **Информационный раздел**:
  - Описание курса и сообщества
  - Приглашение в закрытую группу учеников

- 👥 **Панель администратора**:
  - Отдельный интерфейс для управления
  - Сбор и хранение данных пользователей в `users.csv` (имя, ID и др.)
  - Возможность дальнейшей рассылки

- 🧾 **Логирование действий** (в `bot.log`)

## 🛠️ Технологии

- Python 3.10+
- aiogram 3.x
- Хранение данных в CSV
- Разделение по ролям: пользователь / админ

## 🚀 Как запустить

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `api_token.py` с токеном:
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_id
GROUP_ID=ГРУППА
```

3. Запустите бота:
```bash
python main.py
```

## 📁 Структура проекта

- `main.py` — запуск бота
- `admin.py` — админ-панель
- `users.csv` — база пользователей
- `bot.log` — журнал активности

## 🤝 Контакты и поддержка

Если вы хотите узнать больше о курсе или задать вопрос — воспользуйтесь ботом или присоединяйтесь к группе.
